## D-007 — MacBook computes, Lenovo only hosts

Date: 2026-09-04
Decision: All compute load (pose estimation, 3DGS training, conversion) runs on the MacBook M4; the Lenovo server is used exclusively as a hosting target for the finished web viewer, not as a compute node.
Rationale: The Lenovo has no GPU and is not upgradable (no Thunderbolt), 4 cores CPU-only — significantly slower than the M4 for every task in this project; plus high latency due to distance. Its only real advantage is that it runs continuously and Coolify is there.
Consequences: The Mac is the only machine that must run for the vertical slice — the project can manage entirely without the Lenovo if necessary (then local viewer instead of web). Limit for hosting: ~9 MBit/s upload, see context/architecture.md.

## D-011 — Two independent repos under repos/

Date: 2026-09-04
Decision: The code lives in two independent projects, each complete in itself: `repos/pipeline-3d/` (everything on the Mac) and `repos/robot/` (everything on the JetBot). Truss carries exclusively planning and decisions, no code.
Rationale: The two strands have separate runtime environments (macOS/Apple Silicon vs. Ubuntu 18.04/Python 3.6), separate dependencies and separate error patterns; merging them forces compromises that neither side uses. Kept separate, they can be developed in parallel and demonstrated individually.
Consequences: Both lie as subdirectories in the Truss git history — independent in content (own README, own dependencies, executable without the workspace), not as nested git repos; a later extraction works with `git subtree split`. `repos/` is in `.trussignore`, so map and doctor remain focused on workspace content. AGENTS.md §2 lists `repos/` instead of `repo/`.
Superseded-clause note: D-015 (2026-09-11) replaces the "not as nested git repos" clause above for the robot side — repos/robotic-jetbot/ is a nested clone, git-ignored. The rest of this decision stands.

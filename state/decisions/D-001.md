## D-001 — Phaseless Truss mode for ongoing development

Date: 2026-09-04
Decision: Run Truss without a phase model (no state/phases.md) — no gates, no forbidden lists, no exit criteria.
Rationale: University project with a small team (2-3 people), ongoing iterative development instead of multi-phase lifecycle. Phase overhead brings no added value for quick small wins.
Consequences: No phase gate protection — discipline comes from state/current.md and decisions. Phases can be activated at any time if needed (create state/phases.md + truss render).

## D-006 — Manual control as mandatory, driving algorithm as expansion

Date: 2026-09-04
Decision: The JetBot is driven manually (control UI with live camera view); a driving algorithm is an optional expansion after the first complete vertical slice.
Rationale: Manual driving makes the capture quality directly controllable (loops, stops, viewing angles) and runs immediately without any ML model; autonomy is a separate subproject with its own risk and does not improve the 3D result initially.
Consequences: The control UI with live camera view is an MVP component — not to be confused with the streaming stretch goal in VISION.md, which means reconstruction during the drive. The driving algorithm only gets its own decision when the vertical slice is done.

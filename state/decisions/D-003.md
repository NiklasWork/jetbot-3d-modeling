## D-003 — MASt3R als Pose-Schätzer statt COLMAP

Date: 2026-09-04
Decision: MASt3R (via mlx-mast3r) als primären Pose-Schätzer verwenden, COLMAP als Fallback.
Rationale: MASt3R funktioniert besser als COLMAP bei texturarmen/reflektierenden Innenraum-Oberflächen, läuft nativ auf Apple MLX (1.6-1.9× Speedup vs. PyTorch MPS), exportiert direkt in COLMAP-Format für Brush. COLMAP bleibt als bewährter Fallback (brew install colmap).
Consequences: Abhängigkeit von Python + MLX für Pose-Schätzung. CC BY-NC-SA 4.0 Lizenz — nur nicht-kommerziell (kein Problem für Uni-Projekt). KRITISCH: MASt3R akzeptiert KEINE Fisheye-Bilder — Input muss vorher mit OpenCV entzerrt werden (siehe D-005).

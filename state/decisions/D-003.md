## D-003 — MASt3R as pose estimator instead of COLMAP

Date: 2026-09-04
Decision: Use MASt3R (via mlx-mast3r) as primary pose estimator, COLMAP as fallback.
Rationale: MASt3R works better than COLMAP on textureless/reflective indoor surfaces, runs natively on Apple MLX (1.6-1.9× speedup vs. PyTorch MPS), exports directly to COLMAP format for Brush. COLMAP remains as proven fallback (brew install colmap).
Consequences: Dependency on Python + MLX for pose estimation. CC BY-NC-SA 4.0 license — non-commercial only (no problem for university project). CRITICAL: MASt3R accepts NO fisheye images — input must be undistorted beforehand with OpenCV (see D-005).

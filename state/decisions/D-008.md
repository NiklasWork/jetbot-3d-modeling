## D-008 — Robot software stack remains as delivered

Date: 2026-09-04
Decision: The flashed image (`jetbot-043_nano-4gb-jp45` — JetBot 0.4.3, JetPack 4.5, Ubuntu 18.04, Python 3.6, CUDA 10.2) remains untouched; no update of the robot stack.
Rationale: The classic Jetson Nano ends with JetPack 4.6.6 (JetPack 4 is EOL since November 2024, JetPack 5/6 do not exist for this hardware). An update would thus be 4.5 → 4.6.6 at best, costs a re-flash including rebuilding the preconfigured JetBot software and brings nothing to the project. The image already includes the manual control from D-006.
Consequences: Everything on the robot must make do with this state. If a later expansion needs newer libraries, the path leads via NVIDIA's l4t Docker containers on the same host, not via a host upgrade. No more security updates — the robot does not belong on the open web.

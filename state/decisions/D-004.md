## D-004 — SuperSplat as web viewer on Coolify

Date: 2026-09-04
Decision: Deploy PlayCanvas SuperSplat Viewer (lightweight variant, not the full editor) as self-hosted web viewer on the Coolify VPS. Target format: .sog (Spatially Ordered Gaussians).
Rationale: 100% client-side rendering (WebGPU + WebGL2 fallback), needs no GPU on the server, loads models via URL parameter (?content=URL), dynamic splat budget for mobile. .sog is 15-20× smaller than .ply at full SH quality and supports spatial LOD streaming.
Consequences: Conversion .ply → .sog via `npx @playcanvas/splat-transform` (package name checked on 2026-09-04: a bare `splat-transform` does not exist on npm; tested version 3.3.3). CORS headers needed on the storage endpoint. SuperSplat viewer as static Nginx/Docker container.

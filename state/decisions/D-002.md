## D-002 — Brush as primary 3DGS training engine

Date: 2026-09-04
Decision: Use ArthurBrussee/brush as main tool for 3D Gaussian Splatting training.
Rationale: Most mature Metal-native 3DGS tool (~5k stars, 1.2k+ commits), built-in live viewer (--with-viewer), CLI for automation, WebGPU/WASM export, fits in 6-10 GB of 24 GB Unified Memory. Evaluated alternatives: msplat (faster, but only 59 stars/11 commits, no viewer, experimental), Nerfstudio (needs CUDA — not usable on M4).
Consequences: Rust toolchain as build dependency. Input format is COLMAP or Nerfstudio transforms.json — pose estimation must be upstream. Limit training to 7k-10k steps for thermal safety on the fanless M4 Air. Verified on built binary on 2026-09-04: the switch is called `--total-train-iters`, not `--total-steps`; Brush downscales input images itself via `--max-resolution` (default 1920), so a manual downsampling is not necessary for Brush. The time and quality metrics (~6 min, ~92 %) were adopted unchecked — for real measurements see context/messwerte.md.
Rejected: Nerfstudio — CUDA-only, no functional MPS support for splatfacto/nerfacto. msplat — too immature for production use, no viewer.

## D-012 — Object detection on the robot, 3D placement on the Mac

Date: 2026-09-04
Decision: Object detection runs live on the JetBot (jetson-inference, pre-trained SSD-MobileNet); the mapping of detected objects to 3D coordinates happens downstream on the Mac from the COLMAP poses — not in real-time from odometry.
Rationale: The JetBot has neither wheel encoders nor IMU; a self-guided path from motor commands drifts unworkably far within a few meters. The camera trajectory is calculated by COLMAP anyway and much more accurately (D-009) — to acquire the same information twice and worse would be pure duplication of work. jetson-inference (8,980 stars, MIT) is built for exactly this hardware and JetPack 4.x.
Consequences: The robot shows detections live in the camera view and logs them per frame; the 3D placement in space is created only after the reconstruction. Object labels can thus be placed at the right spot in the 3D model. Ultralytics/YOLO is no candidate on this device — it requires Python ≥3.8, the robot is on 3.6 (D-008).
